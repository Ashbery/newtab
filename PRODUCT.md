# Ashbery 新分頁

## Platform
web

## Product purpose
A personal browser start page for quickly searching the web, opening saved apps, checking the time, and arranging useful widgets over a chosen background.

## Users and operating context
The owner uses a Traditional Chinese interface on desktop and smaller browser windows. The page should remain useful on phones and when opened as a static local file or through GitHub Pages.

## Capabilities and constraints
Preserve Google search and URL navigation, search suggestions, Chinese IME input, clock/date, custom image/video backgrounds, local persistence, shortcuts, folders and optional widgets. Arrangement now follows a predictable home-screen grid with draft/Done/Cancel, intentional folder gestures and visible placement previews. Existing layouts and backgrounds survive; explicitly edited phone placement can be saved separately from desktop geometry. The implementation remains static HTML, CSS and JavaScript without a required build step.

## Brand commitments
Keep the Ashbery identity in the document title and About, Traditional Chinese copy, existing Nachoneko assets and attribution, and the personal character of the page. The owner explicitly removed the visible top-left brand and bottom-left helper controls; secondary actions belong in the right-side tool drawer. The owner supplied DESIGN_RESOURCES.md and asked for a substantial improvement to interactions and UI, with award-winning website craft as an aspirational standard.

The owner subsequently supplied three Nachoneko references and asked for the entire interface, controls and optional animated avatar to follow that character. Silver-grey, powder blue, white, aqua and charcoal are the final visual direction.

## Principles
- Search is immediately available and works even when remote suggestions fail.
- Backgrounds belong to the user; interface controls remain legible over them.
- Frequent actions are discoverable by mouse, touch, and keyboard.
- Visual calm and purposeful motion support a start page used many times a day.
- Judge quality by the rendered result and tested interactions, not by award claims.
