# Nacho 靜態造型素材

為這個個人新分頁專案製作的三款 AI 生成 Nacho 衍生頭像，日期：2026-11-16。使用 OpenAI 內建 `image_gen`，以使用者提供的角色設計參考圖建立一致的角色特徵，再各自生成不同衣裝、髮型與構圖；不是將原本立繪重複裁切或換色。

| ID | 名稱 | 衣裝與髮型 |
| --- | --- | --- |
| `blue` | 冰藍日常 | 長銀髮、冰藍針織外套、奶白襯衫與小緞帶 |
| `knit` | 冬日貓帽 | 短鮑伯髮、深藍條紋貓耳毛帽、冰灰圍巾 |
| `ribbon` | 緞帶微風 | 側編髮、奶白水手領、冰藍緞帶 |

此目錄保存 1024 × 1024 透明 PNG 母版。`extension/icons/` 提供各款 16、32、48、128、512 像素透明 PNG；小尺寸供擴充工具列使用，128／512 像素供造型選擇與頭像使用。所有尺寸由生成圖等比例縮放並保留 alpha，未修改現有 Live2D 模型或加入新模型。

這些是 AI 生成的非官方、個人專案衍生素材，沒有聲稱 Nachoneko 角色的官方授權、原畫作者身分或獨家商標權。原角色及原始參考圖的相關權利仍屬原權利人；本目錄不授予其商業使用權。

`manifest.json` 記錄輸出尺寸與造型。`prompts.json` 保存三次生成的完整提示詞；第一款建立此組風格，後兩款同時參照第一款與使用者的角色設計圖，以保持一致性。
