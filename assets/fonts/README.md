# Clock typeface

The active clock uses **Manrope Light (300)**, self-hosted with a digits-and-colon subset (4.7KB). Source: [Google Fonts Manrope](https://fonts.google.com/specimen/Manrope), CSS API `family=Manrope:wght@300&text=0123456789%3A`, downloaded 2026-11-14. Distributed under SIL Open Font License 1.1; see OFL-Manrope.txt. The interface's existing full Manrope face remains its fallback.
